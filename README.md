# Pandas Sales Data Analysis

## Project Overview

This project demonstrates how Python and Pandas can be used to explore, analyse and visualise business sales data.

The project focuses on monthly sales, number of orders and customer satisfaction. The analysis is used to identify trends and provide simple business insights.

## Objectives

- Explore and understand a structured sales dataset.
- Use Pandas to analyse business data.
- Calculate total and average sales.
- Identify the month with the highest sales.
- Analyse customer satisfaction.
- Create a visualisation of monthly sales.
- Communicate the findings clearly.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains monthly business information for one year, including:

- Month
- Sales
- Number of Orders
- Customer Satisfaction

## Analysis Performed

The project includes:

1. Data creation and organisation using Pandas.
2. Basic data exploration.
3. Summary statistics.
4. Total annual sales calculation.
5. Average monthly sales calculation.
6. Identification of the highest-sales month.
7. Customer satisfaction analysis.
8. Monthly sales visualisation.

## Visualisation

A line chart is included in the Jupyter Notebook to show the monthly sales trend throughout the year.

The visualisation makes it easier to identify changes in sales and observe the overall direction of the business performance.

## Key Findings

- Total annual sales were R206,200.
- Average monthly sales were approximately R17,183.33.
- December recorded the highest sales at R22,800.
- Average customer satisfaction was approximately 87.8%.
- The overall sales trend increased during the year.

## Project Structure

- `Pandas_Sales_Data_Analysis_Portfolio.ipynb` — The complete data analysis notebook.
- `README.md` — Project documentation.

## Conclusion

This project demonstrates practical data analysis skills using Pandas and Python. It shows how business data can be explored, analysed and presented visually to support better understanding of sales performance.

The project also demonstrates the use of Jupyter Notebook and Matplotlib to communicate analytical results clearly.
